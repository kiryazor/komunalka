# Файл распознавания для Tesseract OCR

Здесь должен лежать файл `eng.traineddata` — я не могу скачать его сам
(в моей песочнице нет доступа в интернет), поэтому нужно один раз положить
его сюда вручную:

1. Скачайте файл (≈4 МБ, официальный репозиторий Tesseract):
   https://github.com/tesseract-ocr/tessdata_fast/raw/main/eng.traineddata
2. Положите его в эту папку: `app/src/main/assets/tessdata/eng.traineddata`
3. Удалите этот README.md (Android иначе попытается упаковать его в APK,
   это не страшно, но лучше не засорять assets).
4. Пересоберите проект.

Без этого файла приложение НЕ упадёт — оно автоматически откатится на
ML Kit (см. TesseractScanner.isAvailable() в коде), просто распознавание
будет менее точным на счётчиках с нестандартным шрифтом.
